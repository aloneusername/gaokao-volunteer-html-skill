# gaokao-volunteer-html

中国高考志愿填报 HTML 报告 Skill。它面向“某省某分数怎么报”“专科/本科/3+2 推荐”“帮我生成 HTML 志愿报告”等场景，强调先问清关键信息，再基于官方和公开资料生成可执行的志愿排序报告。它会先判断用户真实适合本科、专科、职业本科还是 3+2，不会默认把 3+2 推给所有人。

![报告预览](screenshots/report-preview.jpg)

## 能做什么

- 先向用户索要必要信息，避免只凭分数盲目推荐。
- 核验省控线、近年投档线、招生计划、学费、学校地址、校区和办学性质。
- 根据分数、排位、批次线、预算和目标判断主赛道；如果成绩足以上较好本科，会明确建议优先本科。
- 只在 3+2 / 三二分段确实适合时展开，并写清楚“专科专业 → 对口本科院校 → 本科专业”。
- 输出单文件中文 HTML 报告，适合打印、分享和手机查看。
- 给出明确的从上到下填报顺序，而不是只罗列学校。

## 必问信息

调用这个 Skill 时，如果信息不完整，它会先问用户：

1. 高考省份和年份。
2. 总分和全省排位。
3. 科类或选科组合。
4. 批次目标：本科、专科、提前批、3+2 等。
5. 地域偏好。
6. 专业偏好和不能接受的专业。
7. 学费预算，以及是否接受民办、中外合作、校企合作、学分互认、国际班。
8. 更重视录取稳、专业好、学校名气、城市、升学还是就业。

## 报告结构

生成的 HTML 报告通常包含：

- 结论首屏
- 假设与边界
- 最终填报顺序
- 院校专业组推荐
- 3+2 / 三二分段专区，按用户情况显示
- 学校画像与排名对比
- 学费与性价比
- 专业横向比较
- 填报操作建议
- 资料来源

## 安装

把仓库中的 `SKILL.md` 放到 Codex skills 目录：

```bash
mkdir -p ~/.codex/skills/gaokao-volunteer-html
cp SKILL.md ~/.codex/skills/gaokao-volunteer-html/SKILL.md
```

重新打开 Codex 后即可使用。

## 示例触发

```text
帮我做一份广东 2026 高考志愿填报 HTML 报告。历史类 362 分，想报广东省内，专业偏计算机和金融，重点看看 3+2。
```

如果用户没有给排位和预算，Skill 会先追问，不会直接开始生成。

如果用户成绩已经明显适合本科院校，Skill 会把报告重心放在本科院校、专业、城市和学费排序上，并说明不建议走 3+2。

## 3+2 适配判断

Skill 会把 3+2 / 三二分段当作有门槛的升学路径，而不是默认推荐项。它会检查：

- 是否属于高职院校与本科高校三二分段专升本协同育人项目，避免和中职高职 3+2 混淆。
- 是否需要转段报名、基本素质考核、专业能力考核或统考科目，避免暗示“录取即本科”。
- 高职专业、对口本科院校、本科专业是否与用户目标一致。
- 用户分数和排位相对该项目近年投档线是稳、冲、极冲还是不现实。
- 用户是否已经能进入更好的本科院校或本科专业组；如果可以，会优先推荐本科。

更适合重点考虑 3+2 的，通常是本科线附近或专科高分段、专业目标明确、愿意接受专科起点和转段考核、且家庭预算能覆盖对应学费的考生。

## 志愿工具方法借鉴

Skill 会借鉴夸克高考等成熟志愿工具的公开产品思路，重点学习流程和判断维度：

- 建立更完整的用户档案：成绩、排位、偏好、预算、毕业规划、职业倾向、体检限制、专项计划、调剂接受度。
- 用排位和近年数据生成冲刺、稳妥、保底梯度，并检查保底是否足够。
- 支持院校优先、专业优先、地域优先、成本优先、升学优先等不同排序策略。
- 引入同位次去向、本省特色院校、本地产业和专业发展信息作为参考。
- 输出志愿表诊断清单，明确哪些项目要删除、后移、只作为极冲或需查专业目录复核。
- 对招生计划、专业代码、选科限制、校区、学费和 3+2 转段去向保持多源核验。

## 数据原则

- 高考政策和分数线优先使用省教育考试院、省招生办、阳光高考平台。
- 学校信息优先使用学校官网、招生网和招生章程。
- 排名只作为参考，必须标注为第三方榜单，不能当作录取依据。
- 3+2 不是默认推荐项，必须结合用户成绩、排位、对口本科质量、专业匹配和转段条件判断。
- 无法核验的信息必须标注“以当年招生专业目录和志愿填报系统为准”。
